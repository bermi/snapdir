## Accuracy check (each claim verified against code)

- Env suffixes + defaults — `config.rs`: IDENTITY_FILE (+IdentitiesOnly=yes),
  PORT (URL wins), KNOWN_HOSTS (UserKnownHostsFile), CONNECT_TIMEOUT=10,
  JOBS=4 with SNAPDIR_JOBS→SNAPDIR_MAX_JOBS fallback, CONTROL_PERSIST=60,
  UMASK="077" (ssh engine only; sftp uses chmod 600 — confirmed in
  sftp_engine.rs batch lines), EXTRA_OPTS validated Key=Value, appended LAST.
- Floor flag list + order — `config.rs::flag_args`: BatchMode,
  StrictHostKeyChecking, PasswordAuthentication=no,
  KbdInteractiveAuthentication=no, ClearAllForwardings,
  KexAlgorithms=sntrup761x25519-sha512@openssh.com,curve25519-sha256,
  curve25519-sha256@libssh.org; Ciphers=chacha20-poly1305,aes256-gcm,
  aes128-gcm (@openssh.com); HostKeyAlgorithms (12 entries, ed25519 →
  rsa-sha2 → ecdsa, certs included, ssh-rsa/DSS excluded); ConnectTimeout.
  MACs deliberately unpinned (AEAD) — documented.
- URL grammar + rejections — `url.rs`: password rejection wording, user/host
  charsets, bracketed IPv6, port 1–65535, bare-`/` and control-char base
  rejection, no percent-decoding, trailing-/ trim.
- OpenSSH floor — `version.rs`: MIN_OPENSSH=(8,5), ssh -V (stderr),
  fail-closed on unparsable, NO override env. Excluded-platform versions
  cross-checked (RHEL8=8.0, Ubuntu 20.04=8.2, Debian 11=8.4, macOS 11=8.1).
  Remote server NOT version-gated (only must offer floor algorithms) —
  stated explicitly.
- Accel toggles — `ssh_engine.rs`: SNAPDIR_SSH_NO_ACCEL=1, FORCE_ACCEL=1
  (designed error naming host/required wire+caps/probe output/remedies),
  PULL_SENDALL=1 (full list), SNAPDIR_SSH_LOCAL_SNAPDIR (test/debug; in crate
  README only). Missing local snapdir → graceful dumb fallback.
- Caps required — PUSH_CAPS="objects-needed,receive-pack",
  FETCH_CAPS="send-pack"; WIRE_VERSION=1 local const pinned by test to
  snapdir_stores::WIRE_VERSION.
- Round trips — push: combined probe + objects-needed + send|receive = 3;
  fetch: caps probe + stream = 2, probe skipped when nothing needed (dispatch
  `[ ! -s "$snapdir_ids" ]` branch). Empty missing set still streams
  manifest-only pack.
- SNAPPACK — `pack.rs`: WIRE_MAGIC="SNAPPACK 1\n", MAX_HEADER_BYTES=128
  (incl. `\n`; longest valid header 95B), MAX_MANIFEST_BYTES=64MiB,
  manifest-must-be-last, commit only at `end`, EOF-before-end hard error,
  duplicates consumed+verified+skipped, manifest payload hash+parse+re-render
  triple check, write_pack validates all ids before any byte, aborts before
  `end` on any failure.
- Plumbing — `cli.rs`: capability line format + println, objects-needed
  fail-closed-before-store-resolution + first-occurrence dedup + empty-stdout
  on error, send-pack `--ids <FILE|->` raw-stdout/stderr-summary,
  receive-pack FileSink-on-file:// + --require-manifest exact-id-after-read +
  silent stdout. `version --capabilities` hidden; older snapdirs clap-error →
  treated as no-accel.
- sync limitation — cli.rs `stream_store_for_adapter` rejects
  Adapter::External; worded as "no in-process streaming surface".
- Fixed entry — matches the external-cli-wiring gate record (push stages into
  cache, pushes from cache root; fetch lands in cache root, manifest last via
  put_manifest).
